# Procedencia del paquete S1

Versión de desarrollo 0.1.0, 2026-11-09. Instrucciones y contrato específicos de LEX AI, redactados para entrada/salida estructurada, contexto suministrado y flujo local → nube → local. No es instalación del plugin de otro proveedor, importación de su base jurídica ni una traducción completa de sus instrucciones. Las referencias siguientes informan patrones de trabajo; no se distribuyen aquí sus archivos, código, conectores, plantillas o motores comerciales.

La investigación [S-R0](../../docs/research/cloud-legal-skills-selection-2026-11-09.md) registra otros candidatos; **no se incorporan** módulos mexicanos de Softlaw AGPL/comercial, el catálogo lawve NC-ND, módulos de licencia desconocida, servicios de pago o el sanitizador por prompt de MiGaceta. Una adopción futura de texto/código ajeno requiere conservar su licencia, atribución, cambios y resolver dependencias, independientemente de que esté publicado en GitHub.

El manifest liga las dos instrucciones locales por SHA-256. Su nombre no autentica procedencia pública, permiso de envío o clasificación de un input. Este documento de procedencia no se carga como instrucciones del modelo; el ejecutor selecciona únicamente la skill pertinente y su contrato. El paquete no concede una nueva licencia sobre la aplicación completa ni altera avisos de terceros existentes.
