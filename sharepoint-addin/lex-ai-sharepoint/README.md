# LEX AI en SharePoint Online

Elemento web SPFx 1.24.1 para páginas modernas. Abre el asistente local del asunto y entrega la selección de la página únicamente al panel HTTPS del equipo después de que este la solicite. El sitio no recibe los mensajes ni el código de sesión del panel.

Desde este directorio usa `npm ci` y `npm run build` con una versión de Node compatible con package.json. El resultado es `sharepoint/solution/lex-ai-sharepoint.sppkg`. La guía de instalación de usuario está en [Complementos de Microsoft 365](../../integrations/LEEME.md).
