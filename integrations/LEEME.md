# LEX AI para Microsoft 365 en macOS

1. Instala LEX AI 0.4.6 en Aplicaciones. Ejecuta **Preparar complementos.command**. Copia los manifiestos de Word y Excel y genera un certificado HTTPS para tu equipo con vigencia de un año.
2. Revisa la huella del certificado mostrado. El comando que imprime el instalador habilita únicamente ese certificado para SSL de localhost en tu llavero de usuario. Luego reinicia Word o Excel y abre LEX AI desde los complementos del documento.
3. En LEX AI selecciona el asunto. En Configuración, usa **Vincular complemento**. Introduce el código de un solo uso en el panel dentro del siguiente minuto. Una sesión vence en 15 minutos. Puedes revocarla desde Configuración.
4. Para SharePoint Online, el administrador carga **lex-ai-sharepoint.sppkg** en el catálogo de aplicaciones de la organización y agrega el elemento web **LEX AI** a una página moderna. En la app de escritorio introduce primero la dirección HTTPS del sitio al generar el código. Después carga la página para que el navegador pueda abrir el panel local. Si el navegador bloquea el panel incrustado, usa **Abrir LEX AI en una ventana del sitio**. La ventana conserva la selección y la vinculación al mismo sitio.
5. Desde cualquiera de los paneles, usa **Ver conversación del asunto** o haz una pregunta. Para incorporar contexto nuevo, selecciona un fragmento del documento Word, celdas de Excel o texto visible de una página de SharePoint. Pulsa **Leer selección**, revisa el texto y usa **Guardar este texto en el asunto**. Las siguientes consultas utilizan el hilo y la biblioteca del asunto. **Editar versión** permite guardar un borrador en el escritorio conservando el mensaje original.

El componente de SharePoint lee el fragmento seleccionado en la página. Para trabajar con el contenido de un archivo de la biblioteca, ábrelo en Word o Excel y usa su panel. El instalador de complementos es para macOS Apple Silicon. El acceso de SharePoint necesita una sesión Microsoft 365 existente y puede depender de la política de red local del navegador.
