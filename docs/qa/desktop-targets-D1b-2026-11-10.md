# D1b: preparación explícita por plataforma

El build ahora selecciona mac-arm64, mac-x64 o windows-x64 y prepara `.desktop/<target>/app`. El corte ejecutable admite sólo Mac del mismo sistema/arquitectura; Windows falla antes de modificar staging porque launcher/runtime siguen pendientes. No construye por cambiar el nombre de un archivo. [Datos y hashes](desktop-targets-D1b-2026-11-10.json).

Se exige inventario revisado de archivos runtime y fuentes con path, bytes y SHA-256. Las fuentes se limitan a clases versionadas permitidas; ya no se copia todo Ollama o el almacén del usuario. Rechaza traversal, alias de mayúsculas/NFC, colisiones padre/hijo, symlinks y archivos alterados antes/después de copiar o preparar dependencias. Reemplazo atómico, sólo sobre payload previo marcado para el mismo target; un fallo conserva el anterior. npm usa offline/ignore-scripts/bin-links=false. Sin brew, descarga de Whisper, modelos o runtimes.

El modelo local es opcional y explícito, desde un bundle ya verificado. Sin modelo, verify-package declara services-only-no-inference: no acredita chat, motor listo o versión distribuible. El launcher existente puede intentar bootstrap, sin habilitar descargas. El wrapper comprueba herramientas/target Rust instalado, impone Cargo offline y pasa target y overlay Tauri absolutos. La base resources:{} evita que JSON Merge Patch conserve la ruta vieja compartida, conforme a [configuración Tauri](https://v2.tauri.app/develop/configuration-files/) y [CLI](https://v2.tauri.app/reference/cli/). El verificador comprueba arquitectura esperada en lugar de exigir universal para cada binario.

Builder y revisor Sol: **11/11**, incluida arquitectura del Node real en Mac; staging completo usa fixtures sintéticas. Root **812/812** y build TypeScript/Vite. Sin build Tauri real, aplicación Intel/Windows ejecutada, firma/notarización o prueba física8GB. D1/D2 siguen abiertos: inventarios reales aprobados, perfil híbrido ligero, launcher y dependencias Windows, ejecución/instalación por plataforma y publicación de activos. Este corte no habilita sus enlaces de descarga.
