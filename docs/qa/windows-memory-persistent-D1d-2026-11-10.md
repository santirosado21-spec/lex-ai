# D1d: arranque del colector separado de consultas

El fallo real de D1c queda preservado. Este protocolo2 optativo inicia un único PowerShell con script fijo y mide arranque hasta el primer snapshot CIM real con máximo10s. Después pide cuatro snapshots nuevos, cada uno con máximo2s/4MiB; no se inicia PowerShell por muestra. El contador de bootstrap no se oculta como warmup ni se presenta como pase del antiguo deadline frío. [Fuentes/estado](windows-memory-persistent-D1d-2026-11-10.json).

Sólo JSON numérico id/pid, una solicitud en vuelo, sin cola, shell, perfiles, bypass, nombres o líneas de comando de procesos. Parser estricto compartido, UTF8 fatal, respuesta/id/límites comprobados incluso ante eventloop retrasado; error/timeout/protocolo/cierre bloquean, con limpieza sólo del colector propio. Diagnóstico conserva categoría/etapa/tiempo, killed, código numérico y señal finita, sin stderr o mensajes crudos. No hay autoarranque o importación en producción. El coste de memoria de PowerShell sigue desconocido.

Revisor detectóP2: una fixture podía morir durante la última consulta y aun así producir PASS. Corregido con observación de error/salida y comprobaciones después de cada await, antes de PASS y del cierre intencional. Una salida previa no se convierte en cierre limpio; sólo exit0 esperado, sin señal/error, satisface cleanup. Regresiones de salida3/error final y salida durante cierre fallan correctamente. Builder29/29, revisor25/25 (subconjunto sin runtime suite) y repetición de la sonda previa. Un primer test del arreglo expuso que el mock desconectado reescribía exit3 a0; se corrigió también el cierre de procesos ya terminados, sin cambiar deadlines.

Workflow público estándar Windows2025 conserva cinco minutos, permisos mínimos, checkout fijado y sin instalaciones, artefactos, secretos o pagos. Sólo el protocolo de smoke cambia a --persistent y se incluye el colector en paths/tests. La fixture sintética tiene vida máxima60s con desconexión IPC, frente a30s del protocolo original. Prueba real pendiente al subir el commit revisado; ni un pase WindowsVM16GB acreditaría instalador, inferencia o equipo físico8GB.
