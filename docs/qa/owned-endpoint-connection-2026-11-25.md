# Owned reader: attest the connected socket before HTTP

Scope: opt-in owned reader only. No product activation, model execution, private input, shared port 11434, downloads, index build or Mac session.

The previous transport selected a free port, spawned a leader, then trusted HTTP version output. This did not bind the connected endpoint to the owned process. A pre-fetch listener snapshot alone would leave a check/connect race.

New transport connects TCP without returning the socket to the HTTP Agent. It checks the owned ChildProcess is alive, compares PID/start-time output from ps, and requires lsof to show the reverse of this exact established TCP tuple in the leader's descriptor table. It rechecks process identity before handing the same socket to HTTP. There is no reconnect/retry or keepalive pool. A substituted listener cannot acquire that existing TCP connection. Each request repeats this procedure. Unsupported platforms, missing inventory, an auxiliary-only listener, different PID/tuple/state, or changed identity fail closed before HTTP headers/body. The production owned reader uses this transport for startup and chat. Tests explicitly inject their synthetic transport factory.

Measured Linux: 25/25 focal tests including the 20 prior owned-runtime synthetic tests. Real harmless Node servers accept a synthetic POST only with the owned descriptor, reject an unrelated listener with zero raw TCP payload bytes, and reject a replacement listener started during verification. Separate mutations removing attestation and returning the socket early both fail. Inventory failure, altered process identity, and pre-abort also deliver zero HTTP bytes. Build and diff check pass.

Limits: Mac lsof/ps format and flow require independent execution with harmless owned server before recommendation. Only the owned leader itself is accepted, not arbitrary descendants. This intentionally sacrifices availability rather than trust a descendant without a stronger binding. PID/start-time checks are not continuous kernel peer credentials. A malicious same-user process able to manipulate the owned process, inherit/pass descriptors, or defeat process inventory is outside this check. Child exit remains distinct from descendant containment. This change does not prove model quality, real runtime compatibility, bounded memory, physical cancellation, or tree cleanup. Runtime stays off and technically blocked on those remaining requirements.
