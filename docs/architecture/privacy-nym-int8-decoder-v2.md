## Content and coordinate contract

Original text is never normalized or repaired. All offsets must remain strict nonboolean integers, positive, ordered, disjoint original codepoints. Every non-whitespace scalar is covered, and original UTF8/UTF16 endpoints are computed independently. All attended contributors and logits remain present, including whitespace and O; no grouping, deduplication, trimming or dropped prefix tokens.

For proof computation alone, N replaces ASCII space with U+2581. Original literal U+2581 blocks. Piece start is0, or the end of an exact admitted whitespace added token. The first ordinary token must begin there and match exactly one marker plus N(slice), except when that original slice starts with ASCII space, where it must match N(slice) exactly. Later tokens match N(slice) with no prefix exception. The61 pinned whitespace added entries (31 newline runs and30 tab runs) require all five metadata flags false and exact original-content equality, and reset piece start. Other added entries block except the separately reviewed ordinary-BPE case below.

The exact30 IDs139..168 may represent ordinary base-BPE space runs only when their pinned base ID and added ID agree, all five flags are false, raw and added content are exactly ID-minus137 markers, and the full original slice is exactly the same number of ASCII spaces (2..31). These do **not** reset piece start; ordinary first/later rules still apply. This relies on the preserved source audit: normalized:false literal-marker added matching occurs before normalization and cannot match the marker-free original; it is absent from normalized-added matching. No other non-whitespace added path is admitted.

A pinned raw fallback entry may contribute one ASCII byte exactly equal to the complete original slice, only after the first ordinary piece token. Multibyte/grouped/repeated/overlapping or first-piece fallback fails. UNK, controls, token loss, invalid masks, overflow and provenance errors block. All81 logits are finite with unique argmax; every non-special row including O has confidence≥0.4. Strict BIO and minimum span confidence remain unchanged; all40 native types remain unmapped. Native results always have diagnosticOnly=true, egressEligible=false, mappingApproved=false, empty detections and null protectionPlan. `offsetContractValidated=false` continues to deny a universal alignment claim.
