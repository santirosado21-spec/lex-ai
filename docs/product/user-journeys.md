# Recorridos

1. **Preparación**: abrir LEX AI, crear el despacho y elegir áreas. Revisar hardware, licencia y tamaño de descarga; iniciar Gemma. Si falta memoria o integridad, mostrar el error y permitir volver a intentar tras corregirlo.
2. **Contrato**: crear asunto con cliente y jurisdicción explícita; importar un contrato sintético; consultar texto extraído y hacer una pregunta. La interfaz espera generación y validación; después muestra análisis y evidencia por separado.
3. **Revisión**: abrir el pasaje y su fuente oficial, comprobar aplicabilidad y vigencia; exportar DOCX como borrador. El corpus se consulta localmente; visitar enlaces oficiales es una acción externa explícita del usuario.
4. **Aprendizaje**: aceptar, rechazar, corregir o marcar una cita; proponer una nota de alcance limitado al asunto. Evaluar estructura y trazabilidad, revisar profesionalmente, aprobar o mantener pendiente. Revertir si procede.
5. **Fallos**: no hay evidencia → abstenerse; formato inválido → explicar; cita falsa → no guardar; motor caído → reiniciar; cambio de asunto → cancelar consulta y limpiar contexto visible.
