# Prueba privada de Rejon.AI · Comercio exterior

Descomprime el paquete en una carpeta local de cada participante. Abre **Abrir Rejon.command** en Mac o **Abrir Rejon.cmd** en Windows con Node.js 22 con soporte de SQLite FTS5 instalado (la integración del proyecto usa 22.23.5). En Linux o Terminal ejecuta `node piloto/abrir.mjs --elegir-perfil` desde esa carpeta. Mantén abierta la terminal mientras trabajas. Si el sistema requiere instalar dependencias para su arquitectura, ejecuta `npm ci --omit=dev --ignore-scripts --no-audit --no-fund` en esa copia.

1. Elige tu perfil y el código del ejercicio. El mismo par reabre los borradores. Un código nuevo inicia un asunto independiente. Los perfiles organizan pruebas dentro de la cuenta del sistema operativo. Cada participante debe ejecutar su propia copia en su equipo. Crea una frase local exclusiva de al menos 12 caracteres y consérvala para volver a abrir el ejercicio. Para restaurar una copia cifrada, utiliza el mismo perfil, código de ejercicio y frase.
2. En Mac puedes usar la clave principal existente del Llavero o introducir una clave temporal con entrada oculta. En Windows/Linux se usan claves temporales. En los tres sistemas puedes elegir una clave temporal principal, la de Lorenzo o ambas, y alternarlas o usar la segunda como respaldo si falta la primera. El paquete se distribuye sin credenciales. Para dar de alta el segundo ítem con Acceso a Llaveros en macOS, crea una contraseña de aplicación en tu llavero de inicio de sesión con nombre exacto **LEX AI.product.openai** y cuenta **product-api-key-lorenzo**. El ítem principal usa la cuenta **product-api-key**. La opción «alternar» cambia de cuenta en cada solicitud nueva de esa sesión. «Respaldo» recurre al segundo ítem si falla la lectura del primero antes de enviar. Un error HTTP del proveedor se muestra para que decidas cómo continuar.
3. Usa exclusivamente un asunto ficticio. Puedes escribir los campos o seleccionar **Leer documento ficticio** y elegir `piloto/factura-ficticia.txt`. La lectura automática requiere Ollama en 127.0.0.1:11434 y el modelo local `qwen3.5:2b-q4_K_M`. Si deseas instalarlo, Ollama proporciona `ollama pull qwen3.5:2b-q4_K_M`. El lanzador no hace esa descarga. Confirma los campos sugeridos y el tipo de documento.
4. Para probar el recorrido completo de un documento, pulsa **Crear documento de práctica** dentro de un ejercicio cifrado nuevo. Despliega **Revisar protección local**, verifica las sustituciones y deja seleccionada la opción de guardar el texto. Guarda. En **Nota del expediente protegido**, abre la vista del mensaje que recibiría OpenAI. Comprueba el marcador del proveedor, los hechos y el artículo seleccionado. Si un hecho esencial quedó oculto, el ejercicio lo indica y puedes seguir en el editor con otra tarea o elegir un pasaje de la biblioteca. La solicitud explícita de generación consume API de la cuenta elegida. La aplicación conserva los nombres y el texto libre en el equipo. El documento de práctica generado en este equipo permite enviar al proveedor los hechos comprobados del ejercicio, sus marcadores y el pasaje público. La tarea general de importación utiliza el tipo documental confirmado y referencias públicas. La operación, tasa, plazo o preferencia requieren revisión individual con información suficiente y la versión normativa aplicable.
5. Revisa y edita el borrador. En **Consultar soporte local** puedes cotejar el texto guardado. Al editar, **Insertar marcador** añade el dato elegido en la posición del cursor. **Datos originales** muestra cómo quedará la exportación. Descarga los archivos Word, Excel y PowerPoint. Abre cada uno y comprueba el cliente, el asunto, el contenido editado y las referencias.
6. Para terminar, cierra la terminal. La base de pruebas queda bajo `~/.rejon-piloto-comercio/<perfil>/<ejercicio>`, en el archivo `rejon-protegido.sqlite`. El lanzador guarda los contenidos de los registros con AES-256-GCM. Los identificadores internos y tipos de registro siguen visibles en SQLite. Las exportaciones de Office contienen los originales para uso del abogado. Si existe un ejercicio anterior de r1–r3, la primera apertura copia sus registros al nuevo archivo dentro de una transacción. La copia anterior `lex.sqlite` se conserva en claro. Los cambios posteriores se guardan en el archivo cifrado. Esta edición se limita a ejemplos ficticios. Los artículos del índice y los nuevos PDF en cuarentena tienen estados de revisión diferentes.

El navegador se comunica con un proceso en loopback. La aplicación no publica una web ni sincroniza expedientes entre participantes. La cuota del proveedor se administra en cada cuenta. El límite de peticiones del piloto es por proceso, no por organización.

Cada generación completada guarda un recibo local en `uso-openai.jsonl` dentro del ejercicio con la cuenta seleccionada, modelo y tokens reportados. La factura y los intentos rechazados se consultan en el proveedor.

### Investigar otro artículo

Una vez guardado un expediente, abre **Biblioteca federal**. Para probar una pregunta sobre cupos, escribe «cupo», elige la Ley de Comercio Exterior y abre el artículo 23. Para investigar otra operación, cambia los términos y elige el artículo que el abogado considere pertinente. En «Usar en el expediente» puedes leer y seleccionar un pasaje, incluso en artículos extensos. Pulsa **Preparar nota con este pasaje** y revisa el texto antes de generar. La búsqueda se queda en el equipo. El servidor compone el mensaje con el pasaje público y su edición. La nota guarda la referencia utilizada y se puede volver a abrir, editar y exportar. Revisa el artículo completo, sus transitorios y la fecha de aplicación.

Al leer un documento ficticio de texto, PDF con texto o Word, despliega **Revisar protección local**. La pantalla resalta las sustituciones propuestas por Ollama y las reglas locales. Puedes alternar entre el texto con sustituciones y el texto restituido para detectar omisiones o excesos. La comprobación recae sobre el texto extraído del archivo. El borrador en la nube sigue recibiendo sólo el mensaje previamente mostrado, que puede incluir el pasaje público elegido. El soporte de un documento importado por el usuario se conserva en el expediente cifrado si se seleccionó al guardarlo. Puedes consultarlo al reabrir el mismo ejercicio. Su texto libre se queda en el equipo.
